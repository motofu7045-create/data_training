## 読み方

- 各ファイルは「何ができるか」「いつ使うか」「似た機能との違い」「設定する場所」を1か所にまとめている
- **試験に出やすい**と書いた見出しは、似た機能の使い分けが問われやすいところ
- 各セクションの最後に、元になった Trailhead の単元へのリンク（出典）を付けている
- 設定する場所は、無料の Developer Edition で実際に開いて確かめると覚えやすい

## 注意

- 教材に含まれていた Salesforce ヘルプの記事（8本）と YouTube 動画（1本）は、作業環境から表示できず読めていない。各ファイルの冒頭に「読めなかった教材」として書いている
- Salesforce は年3回のリリースで機能や名前が変わる。特に Agentforce は変化が速い
