## 勉強のやり方

Trailhead は「どこをクリックするか」を教える作り。試験で問われるのは「この状況でどの機能を選ぶか」。
そのため、次のやり方で進める。

1. **問題から入る**: 先に問題を解き、間違えたところだけ説明を読む
2. **比較表を作る**: 似た機能を表にして、「何ができるか」「いつ使うか」を自分の言葉で書く（[comparison.md](comparison.md) に追記していく）
3. **実務と結びつける**: 2026年8〜9月の案件で見た設定が、どの機能だったかをつなげる
