# 似た機能の使い分け

試験では似た機能が選択肢に並ぶ。「正解がなぜ正解か」より「他の選択肢がなぜ違うか」を言えるようにする。

## オブジェクトの関係

| | 参照関係 | 主従関係 |
| --- | --- | --- |
| つながり | 緩い | 強い |
| 親を削除すると | 子は残る | **子も削除される** |
| 積み上げ集計項目 | 使えない | **使える** |

## アクセス権

### 何を決めるものか

| 機能 | 決めるもの | ポイント |
| --- | --- | --- |
| プロファイル | オブジェクト・項目の権限（基本） | ユーザごとに**1つだけ** |
| 権限セット | オブジェクト・項目の権限（追加） | **一部の人だけ**に権限を足すときに使う |
| ロール | どの**レコード**が見えるか | 項目の権限ではない |
| ページレイアウト | 画面の見た目 | **セキュリティにはならない** |

### レコードの見え方（4段階で「広げていく」）

1. **組織の共有設定**: 一番狭い基準を決める（例：非公開）
2. **ロール階層**: 上司が部下のレコードを見られる（**縦**の共有）
3. **共有ルール**: 特定のグループに広げる（**横**の共有）。同じロールどうしの共有はこれ
4. **手動共有**: 個別のレコードを特定の人に共有する

プロファイルの「参照」権限はオブジェクトを開く権利があるだけで、**他人のレコードが見えるようにはならない**。

## 入力の制御

| 機能 | 使う場面 |
| --- | --- |
| 項目の「必須」 | **常に**必須にしたい |
| 入力規則 | **条件つき**で必須にしたい、値をチェックしたい |
| 項目の依存関係 | 選択リストの選択肢を、別の項目の値で絞り込みたい |

## データの取り込み

| | データインポートウィザード | データローダ |
| --- | --- | --- |
| 件数 | **5万件まで** | **500万件まで** |
| 対象 | 主な標準オブジェクトとカスタムオブジェクト | ほぼすべてのオブジェクト |
| できること | 追加・更新 | 追加・更新・**削除・エクスポート**も |
| 使う場面 | 少量を画面から手軽に | 大量・定期的・削除やバックアップ |

## 自動化

- 今の試験では、自動化の答えは基本的に**フロー**
- ワークフロールールとプロセスビルダーは廃止に向かっていて、新しくは作れない

## レポート

| 機能 | 使う場面 |
| --- | --- |
| カスタムレポートタイプ（関連レコードの有無を問わない） | 「〜が**ない**ものも含めたい」 |
| 結合レポート | **別々のレポートタイプ**のデータを1つの画面に並べたい |

## 営業

- リードの取引開始で作成されるもの: **取引先**と**取引先責任者**。**商談は任意**

## サービス（ケース）

| 機能 | 使う場面 |
| --- | --- |
| メール-to-ケース | **メール**で届いた問い合わせをケースにする |
| Web-to-ケース | **Webサイトのフォーム**から送られた問い合わせをケースにする |
| ケースの割り当てルール | ケースを**誰が担当するか**を自動で決める |
| エスカレーションルール | 一定**時間**対応されていないケースを上の担当者に回す |

## 生産性

- クイックアクション: レコードの画面から、決まった項目だけをワンタップで更新・作成する
